# Research Limitations / 研究局限

[Project overview](../README.md) · [Rubric](evaluation-rubric.md)

## 误差与风险分类 / Error and risk taxonomy

| 标签 / Label | 含义 / Meaning | 使用边界 / Boundary |
|---|---|---|
| Intent / 意图误读 | 对任务、约束或隐含需求理解偏离 / Misreading intent or constraints | 以原问和追问为依据，不能替用户编造偏好。 |
| Context / 语境错配 | 实体、语域或文化含义错配 / Entity, register, or cultural mismatch | 不把存在多种解释自动记为错误。 |
| Generalization / 过度概括 | 将局部观察推广到群体或制度 / Unsupported generalization | 与是否可用作研究假设分开。 |
| Causality / 因果越界 | 将相关、类比或理论写成已确认机制 / Treating association or analogy as a demonstrated mechanism | 缺直接证据时标未核实或解释性，不直接判事实为假。 |
| Temporal / 时点错配 | 混用历史、当前、版本或预测 / Historical, current, version, or prediction mismatch | 需要对应时点的证据。 |
| Factual / 事实错误 | 已核查命题被直接证据反驳 / Verified factual contradiction | 未核实不能归入此类。 |
| Calibration / 校准不足 | 未合理说明未知、条件或解释边界 / Insufficient qualification of uncertainty | 可以与FA=NE并存，分别评价措辞和事实。 |
| Evidence gap / 材料缺口 | 缺截图、原帖、引用解析或版本 / Missing image, post, citation mapping, or version | 是研究材料局限，不自动归罪模型。 |

每个案例的标签需附具体证据。没有证明的幻觉、伪造来源或文化偏见，不使用确定性结论。风险标签不是错误频率统计。

## 解释、修订与复测 / Interpretation, revision, and retesting

替代解释至少考虑：任务可能允许的另一种理解、表达的教学简化、当时版本与当前版本差异、输入省略以及证据采集缺失。改写回答是改进建议，不冒充历史输出或已执行的模型复测。本轮未进行控制变量复测，没有计算提升幅度。

Alternative explanations include legitimate task interpretations, pedagogical simplification, version changes, incomplete inputs, and capture limitations. Suggested rewrites are proposals, not historical messages or observed retest outcomes.

## 评审者与研究局限 / Reviewer role and limitations

本报告由AI辅助开展资料核查与评分，用户负责选题范围和后续审核。多代理分工不等于多名独立人类评分员；未进行盲评、评审者一致性检验或统计显著性分析。分值是可修订的研究者式初评，不能宣称已经通过雇主认证或官方考试。

This is an AI-assisted analytical review. Collaboration among agents does not establish independent human ratings, blinded assessment, or inter-rater reliability. The scores are reviewable judgments, not certified professional assessment results.

新增网页的正文、发布日期与版本范围均按实际读取情况记录。无法核查的部分在对应案例保留NE或开放问题，不用“已验证”笼统覆盖整个回答。
