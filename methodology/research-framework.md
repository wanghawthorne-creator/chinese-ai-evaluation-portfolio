# Research Framework / 研究框架

**Chinese AI Evaluation Portfolio · Phase 2 · 私有审核稿 / Private review draft · 2026-11-11**

本协议适用于用户批准的CEA-028、022、021、020、019、011、007、008、004、001。10个案例来自9个普通ChatGPT对话；007与008来自同一对话，任务不同。本轮评分不涉及用户人格、公众人物人格或任何企业雇佣评测项目。

This protocol covers ten approved case units from nine ordinary ChatGPT conversations. Cases 007 and 008 share a conversation but address different tasks. The protocol is project-specific and is not an official Google, RWS, or TELUS Digital examination rubric.

## 研究目的 / Research purpose

检查中文语用、文化解释、复杂意图、动态信息与证据表达如何共同影响回答质量。研究材料来自用户真实交互，不是随机抽样的模型基准集。旨在形成可追溯的研究判断，不估计模型总体准确率。

The review examines pragmatic meaning, cultural interpretation, complex intent, temporal relevance, and evidential framing in authentic interactions. It is a purposively selected qualitative evaluation, not a representative model benchmark.

## 材料与分析单位 / Evidence and units

- 以实际取得的原始用户消息、AI消息和指定追问为依据，候选摘要不能代替原文。每案界定纳入的子问题、消息ID和时间；不把复合输入中的一个子任务评分说成整段回答的质量。
- 保留私有原文快照与消息摘要哈希，交付档案仅使用经过脱敏的必要引文。学校身份、田野人物与机构、年龄和生日组合及账户信息不进入展示副本。
- 历史回答按原问时点评估。2026-11-11新增检索只证明其实际能支持的命题，不能自动复原早期产品版本、搜索排名或用户看到的截图。
- 未取得完整截图、原帖、历史网页或历史引用解析时，单列材料缺口。工具只保留引用token，不能据此断言原AI没有引用或编造来源。

The unit is a declared question–response segment, including specified follow-ups. Missing material is distinguished from demonstrated response defects. Newly retrieved sources do not reconstruct historical SERPs or unobserved interface states.

## 评分步骤 / Evaluation procedure

1. 确定原始输入、输出、时间与评测范围 / Define the source messages, time, and task boundary.
2. 提取用户显性约束与合理隐含需求 / Identify explicit constraints and defensible implicit intent.
3. 将可核查事实、理论解释、规范判断、假设与预测分开 / Separate factual claims, interpretations, normative views, hypotheses, and predictions.
4. 使用适合命题和时点的来源逐项核查 / Verify claims against sources appropriate to their scope and time.
5. 仅对适用且可评的维度给0–4整数分 / Score only applicable, assessable dimensions using integer anchors.
6. 记录支持引文、替代解释、改进建议与材料局限 / Record evidence, alternative readings, improvements, and limitations.
7. 复核引文定位、来源对应、分值理由、缺失值与隐私 / Check provenance, claim–source links, score rationales, missingness, and privacy.

## 事实核查状态 / Claim verification states

| 状态 / Status | 定义 / Definition |
|---|---|
| Supported / 有支持 | 来源直接支持所述范围内的命题 / Direct evidence supports the claim within its stated scope. |
| Partially supported / 部分支持 | 只支持较窄范围或部分成分 / Evidence supports only part of the claim or a narrower scope. |
| Contradicted / 有反证 | 有直接不相容的证据 / Direct evidence conflicts with the claim. |
| Unverified / 未核实 | 没有足以裁定的证据；不等于错误 / Evidence is insufficient to decide; this does not mean false. |
| Interpretive / 解释性 | 理论解读、价值判断或研究假设，不能强设唯一事实答案 / Interpretation, normative judgment, or hypothesis without a single factual answer. |
| Not assessable / 无法评定 | 缺原图、原文或关键背景 / Essential source material or context is unavailable. |

## 缺失值与评分解释 / Missingness and score interpretation

**NA — Not applicable / 不适用**：该任务无需此维度，例如纯创作文案无需外部事实来源。**NE — Not evaluable / 证据不足以评分**：维度适用，但关键历史状态、原图或来源无法取得。两者都不等于0分；不补值、不计平均。

NA and NE are retained as missing-value categories. They are never converted into zero. Scores are ordinal judgments tied to the declared case scope; the review does not calculate a composite score, cross-case league table, model accuracy rate, or measured performance gain.

**4分是本协议范围内的最高锚点，不代表无所不知、绝对正确或用户已经满意。** 事实不明不能自动给低准确性分；过度确定的措辞可在UC维度单独评估。
