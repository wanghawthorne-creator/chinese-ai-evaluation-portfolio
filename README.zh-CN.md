# 中文 AI 评测作品集：搜索意图、文化语境与信息质量研究

**Chinese AI Evaluation Portfolio**  
Evaluating Search Intent, Cultural Context, and Information Quality in Chinese-Language AI Systems

独立 AI 评测研究 · 双语案例作品集 · 评测版本 v1.0

## 项目概述

本项目研究中文AI回答如何理解用户意图、处理文化语境、支持事实断言并表达不确定性。材料来自经过批准的真实交互必要摘录，并结合可追溯的外部来源核查。

当前收录**10个案例单元，来自9个普通ChatGPT对话**。CEA-007与CEA-008是同一对话中的不同任务。独立的网页结果轨道评测了**7条新检索网页，分属CEA-020、CEA-021和CEA-022**。这些网页均在**2026年11月11日**取得，不代表历史搜索排名的复现。

这是AI辅助的个人独立研究项目，不是受RWS、TELUS Digital、Google或其他雇主委托的项目，也不代表在这些公司的工作经历或官方认证评测。

## 研究目标

- 区分字面表达与真实交际意图，关注非正式中文、社群称谓及隐含约束。
- 评估文化解释，同时识别刻板印象和缺少证据的泛化。
- 将可核查事实、理论解释、假设与因果断言分开。
- 检查来源范围、发布日期和产品版本是否足以支持相应结论。
- 通过明确标准、具体证据、替代解释和局限，使评审判断可复核。

## 评测维度

两条轨道使用不同标准，不把AI回答质量和网页相关性混为一谈。

| Track A — AI回答评测 | 代码 |
|---|---|
| 意图理解 | IU |
| 语义相关性 | SR |
| 文化语境理解 | CC |
| 事实准确性 | FA |
| 时效性 | TR |
| 来源可信度 | SC |
| 回答有用性 | RH |
| 不确定性表达 | UC |

Track B分别评估**查询结果相关性（WR）、权威与证据适配（WA）、时间匹配（WT）、文化与语境适配（WC）**。网页命题的准确性另按现有证据核查。

适用维度采用本项目自定义的**0–4分序数锚点**。**NA**表示不适用，**NE**表示证据不足以评分，二者都不等于0分。本项目不计算综合分、模型准确率或跨案例排行榜。完整定义见[评测标准](methodology/evaluation-rubric.md)。

## 研究方法

1. 明确批准的原问、回答片段及纳入的追问链。
2. 识别显性约束与有依据的隐含需求。
3. 区分原答命题、背景前提和评审者提出的核验问题。
4. 使用适合命题及历史时点的来源核查关键断言。
5. 为分值保留支持摘录、替代解释、改进建议及证据缺口。

仓库只分发必要的匿名化摘录，不上传完整私人聊天档案或可识别的私人定位信息。缺少截图或历史引文映射属于研究材料局限，不能自动记为AI错误。完整流程见[研究框架](methodology/research-framework.md)。

## 核心研究发现

- **语境会改变词义。** bot的社交账号解释与Agent产品含义不同；称谓语境缺失时，应澄清而不是编造来源。
- **解释连贯不等于证据充分。** CEA-028组织了清晰的解释，但将有条件的个人观察转为未测量的总体与因果断言。其关键事实保留NE，而不是直接判错。
- **边界意识可以是回答优势。** CEA-019保留模拟论证的前提；CEA-001区分理论解释与经验研究；CEA-022区分教学情境、建议方法与已完成田野。
- **核查应落实到具体命题。** CEA-021存在可定位的官方与研究来源，但对信任研究的概述压缩了信息维度、信任维度和模型之间的重要差别。
- **版本与命题归属不可混淆。** CEA-020区分旧研究摘要与后续版本；对评审推论的反证或对用户前提的检验，不能算作AI作出了该断言。

各项结论的证据边界见[核心研究发现](reports/key-findings.md)。

## 研究局限

本项目采用目的性选择，不是代表性基准集。评分是AI辅助的初评判断，没有独立人类盲评、评审一致性估计或控制变量复测；不能据此推断模型总体表现、用户满意度或因果效果。

部分原帖、图片、原书版本、历史产品状态及引文映射尚未取得。当前网页不能自动证明过去功能。4分只适用于声明且已核的范围：例如CEA-008的FA分数只覆盖歌曲元数据；CEA-022的只覆盖方法事实与农普时点，不证明田野成果已发生。详见[研究局限](methodology/limitations.md)。
